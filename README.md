A small runtime choke-point in front of agent tool calls. Reads execute. Writes are planned, then approved. Some tools are denied in **code**, not in the prompt. Every decision is audited (args hashed). MIT kernel, synthetic demos, tests in CI.

This is not a hosted SaaS, not vendor TPRM, and not a red-team product.

**Start here:** [lattice-mcp](https://github.com/popuripk/lattice-mcp)

Want the deny-in-code drill on a fake workplace (compensation always denied): [self-service-mcp](https://github.com/popuripk/self-service-mcp).

Other public repos are experiments (Python twin, agent loop, eval, orchestrator, memory, warehouse mock). They are not a platform and not what I am asking anyone to deploy.
